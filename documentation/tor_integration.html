Overview

This guide explains how to run Tox bootstrap daemons and clients completely over Tor. All traffic flows through the Tor network - no direct internet connections.

What we achieve:
  • Hide bootstrap node IP addresses
  • Enable clients behind restrictive firewalls
  • All communication via Tor/TCP (no direct UDP exposure)
  • Complete anonymity for network participants

Architecture

┌─────────────────────────────────────────────────────────────────────────────┐
│                        TOX CLIENTS (TCP-only + torsocks)                       │
│                    torsocks → Tor → .onion addresses only                     │
└──────────────────────────────┬──────────────────────────────────────────────────────┘
                               │ TCP
┌───────────────────────────────▼──────────────────────────────────────────────┐
│                      Tor Hidden Service                      │
│                                                       │
│   yournode.onion:33445 (DHT)                              │
└──────────────────────────────┬──────────────────────────────────────┘
                                 │ TCP
┌───────────────────────────────▼──────────────────────────────────┐
│                    socat Bridge (DHT only)                │
│                                                       │
│   TCP:33445 ←→ UDP:33445  (DHT)                          │
└──────────────────────────────┬──────────────────────────────────────┘
                                │ UDP
┌───────────────────────────────▼──────────────────────────────┐
│                   tox-bootstrapd                      │
│                                                       │
│   - DHT (peer discovery) - UDP internally            │
│   - TCP relay (peer communication) - UDP internally │
└─────────────────────────────────────────────────────┘

Bootstrap Daemon Setup

Install Dependencies

sudo apt update
sudo apt install socat tor

Configure Bootstrap Daemon

Edit /etc/tox-bootstrapd.conf:

pid_file_path = "/var/lib/tox-bootstrapd/tox-bootstrapd.pid";
keys_file_path = "/var/lib/tox-bootstrapd/keys";
start_port = 33445;

enable_ipv6 = true;
enable_ipv4_fallback = true;
enable_lan_discovery = false;
enable_tcp_relay = true;
enable_motd = false;

tcp_relay_ports = [ 4444 ];  // Single port on localhost; Tor maps 443 -> 4444

// IMPORTANT: Bind to localhost only (for Tor setup)
bind_localhost = true;

// ================================================================================
// BOOTSTRAP NODES: READ AT RUNTIME FROM THIS CONFIG FILE
// ================================================================================
// The daemon reads bootstrap_nodes from this config file when it starts.
// - With nodes: Daemon connects to the DHT network via these peers
// - Without nodes: Daemon starts but remains isolated
//
// Replace the example below with your own Tor-based nodes' .onion addresses and public keys.
// Each node entry requires: address (hostname), port, and public_key (32 bytes hex)
//
bootstrap_nodes = (
    // Add your Tor-based bootstrap peers here:
    {
        address = "yourfriend1.onion",
        port = 33445,
        public_key = "YOUR_FRIEND1_PUBLIC_KEY..."
    },
    {
        address = "yourfriend2.onion",
        port = 33445,
        public_key = "YOUR_FRIEND2_PUBLIC_KEY..."
    }
);
// ================================================================================

    

        Important: enable_tcp_relay = true is required for TCP-only clients!

        Important: bind_localhost = true binds the daemon to 127.0.0.1 only,
        so it's not publicly reachable - only socat (localhost) can connect.

        Important: You must add your own Tor-based bootstrap nodes
        in the bootstrap_nodes list! Without these, the daemon cannot connect
        to the DHT network.
    


    
Socat Bridge (DHT only)

    
    

        Important: Only the DHT needs socat! The TCP relay already uses TCP natively.
    

    
    
Create a script for the DHT bridge only:

    
#!/bin/bash
# Only DHT port needs socat bridge (UDP↔TCP)
# TCP relay is already TCP - no bridge needed

socat TCP-LISTEN:33445,fork UDP:127.0.0.1:33445,bind=127.0.0.1,reuseaddr &

echo "DHT socat bridge started on port 33445"

    
    
Or create systemd service for DHT bridge:

    
# /etc/systemd/system/tox-socat.service
[Unit]
Description=Tox DHT UDP↔TCP Bridge
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/socat TCP-LISTEN:33445,fork UDP:127.0.0.1:33445,bind=127.0.0.1,reuseaddr
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

    
Tor Hidden Service

    
    
Edit /etc/tor/torrc:

    
# Hidden service configuration
HiddenServiceDir /var/lib/tor/tox_bootstrap

# DHT port (Tor:33445 -> localhost:33445)
HiddenServicePort 33445 127.0.0.1:33445

# TCP relay (Tor:443 -> localhost:4444)
HiddenServicePort 443 127.0.0.1:4444

    
    
Create the hidden service directory:

    
sudo mkdir -p /var/lib/tor/tox_bootstrap
sudo chown -R tor:tor /var/lib/tor/tox_bootstrap
sudo chmod 700 /var/lib/tor/tox_bootstrap

    
    
Start Tor:

    
sudo systemctl start tor
sudo systemctl enable tor


    
Getting Your .onion Address

    
sudo cat /var/lib/tor/tox_bootstrap/hostname

    
    
Output will be like:

    
abcd1234567890abcdef.onion

    
    

        Save these! You'll need:

Client Setup

    
    

        
Step 1: Install Dependencies

        
sudo apt install torsocks

    

    
    

        
Step 2: Configure Client for TCP-Only Mode

        
TCP-only mode is REQUIRED for Tor integration:

        
// In your client code
Tox_Options *opts = tox_options_new(NULL);
opts->udp_enabled = false;  // Force TCP only via relays

Tox *tox = tox_new(opts, NULL);
tox_options_free(opts);

    

    
    

        
Step 3: Use .onion Bootstrap Addresses

        
// Bootstrap to your Tor-based nodes
tox_bootstrap(tox, "yournode.onion", 33445, your_pubkey, NULL);

// Add TCP relays
tox_add_tcp_relay(tox, "yournode.onion", 443, your_pubkey, NULL);

    

    
    

        
Step 4: Run Client with torsocks

        
# Run client through Tor
torsocks ./your-tox-client

# Or for debugging:
TORSPROXY=127.0.0.1:9050 ./your-tox-client

    

    
    
Complete Client Example

    
#include "tox.h"

int main(void)
{
    // Enable TCP-only mode (REQUIRED for Tor)
    Tox_Options *opts = tox_options_new(NULL);
    opts->udp_enabled = false;
    
    Tox_Err_NEW err;
    Tox *tox = tox_new(opts, &err);
    tox_options_free(opts);
    
    if (err != TOX_ERR_NEW_OK) {
        printf("Failed to create Tox: %d\n", err);
        return 1;
    }
    
    // Your bootstrap node's public key (32 bytes)
    uint8_t pubkey[32] = { /* your node's public key */ };
    
    // Bootstrap to .onion address
    tox_bootstrap(tox, "yournode.onion", 33445, pubkey, NULL);
    
    // Add TCP relay
    tox_add_tcp_relay(tox, "yournode.onion", 443, pubkey, NULL);
    
    // Main loop
    while (1) {
        usleep(1000 * tox_iteration_interval(tox));
        tox_iterate(tox, NULL);
    }
    
    tox_kill(tox);
    return 0;
}


    
Complete Startup Sequence

    
    
# 1. Start Tor
sudo systemctl start tor

# 2. Start socat bridges
sudo systemctl start tox-socat

# 3. Start bootstrap daemon
sudo systemctl start tox-bootstrapd

# 4. Verify Tor is running
systemctl status tor

# 5. Verify socat is running
ss -tlnp | grep socat

# 6. Verify bootstrap daemon
systemctl status tox-bootstrapd


    
Important Notes

    
    

        
    
            
  • Tor adds latency - All operations will be slower
    • 
            
  • Update monthly - The DHT protocol may change
    • 
            
  • Keep .onion addresses secret - For true anonymity
    • 
            
  • TCP relay required - TCP-only clients need relays
    • 
            
  • Two ports - DHT (33445) + TCP relay (443)
    •
